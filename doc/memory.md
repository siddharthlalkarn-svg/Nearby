## Project Context

- **Design System**: Global typography, shadows, colors, and components (Milestone 2, 3, 4) have been systematically updated to be 100% compliant with `design.md`.
- **Enhanced Map**: Includes dynamic zooming to fit all results, rich interactive price markers (like Airbnb), and active state tracking.
- **Provider Dashboard**: Providers now have a dashboard to view active listings and mock stat chips (Views, Saves, Rating) before creating new listings.
- **Bookmarks (Saves)**: Travelers can now save (heart) experiences, syncing seamlessly between the Feed and Detail views.
- **Conversational Search**: Users can type their mood in natural language (e.g. "I want food under 500") and be routed directly to matched results.
- This is a **new project**.
- The application is a two-sided local experience discovery platform.
- Travelers are the primary user experience.
- Providers have a minimal listing flow to prove the two-sided concept.
- The core differentiator is personalized, constraint-aware recommendation.
- Recommendations should consider interests, available time, budget, distance, ratings, and relevant group/accessibility constraints.
- Results should visibly explain why they were recommended.
- Changing constraints should cause recommendations to adapt.

The supplied Stitch ZIP is the visual reference for the intended interface direction.

Important qualities include:

- warm cream base
- pink primary accent

- rounded cards and controls
- asymmetric/masonry composition
- sticker-like match badges

- strong hierarchy without clutter

## Responsive Priority

- Mobile phone is the primary target for traveler-facing screens.
- Desktop and tablet are adaptations from the mobile foundation.
- A desktop-only polished result is not sufficient.

## Scope Discipline

The MVP is centered on:

- traveler quick input
- seeded/mock provider experiences
- recommendation ranking
- explainable recommendation results
- adaptive re-ranking
- minimal provider listing creation

Stretch features remain secondary.
