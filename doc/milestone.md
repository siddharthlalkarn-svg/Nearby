# Milestones

## Workflow

Development follows milestones in order.

Complete the active milestone before spending meaningful effort on later milestones.

---

**Status:** COMPLETED

- establish the unnamed-brand rule
- prepare the application foundation

---

## Milestone 2 — Core Traveler MVP

**Status:** COMPLETED

### Goal

Build the primary traveler experience from scratch with a strong mobile-first UI and a visible personalized recommendation loop.

### Required

- Mobile-first application shell/layout.
- Traveler quick-input/profile flow.
- Interest multi-select.
- Budget control.
- Available-time selection.
- Group type selection.
- Recommendation results.
- Experience cards.
- Match percentage.
- Visible "why recommended" reasoning.
- Constraint filters.
- Adaptive re-ranking when budget/time/filters change.
- Responsive desktop adaptation.
- Visual direction aligned with the supplied Stitch reference and later `design.md`.

### Acceptance Criteria

A traveler should be able to:

1. enter basic preferences and constraints
2. request recommendations
3. receive ranked experiences
4. understand why an experience was recommended
5. change a major constraint
6. see recommendations adapt

The complete flow should be comfortable to use on a mobile phone.

## Stretch Features

Only consider these after the core MVP is stable:

- conversational/chat input
- itinerary builder
- weather-based reshuffle
- enhanced map visualization
- provider dashboard/stat chips
- bookmarks/share enhancements

Never sacrifice the core recommendation loop for a stretch feature.
